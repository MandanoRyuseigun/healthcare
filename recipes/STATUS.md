## 決まっていること

- 対象：一人暮らし・料理初心者
- 価値：AIで「わが家（器具・常備品・予算）に合わせる」「目的に合わせる」。使うほど育つ
- 「みんなのレシピ」（公開）はおまけ。SNS化しない。効果をうたう健康表現をしない
- 収益：無料（運営の安いモデル・回数制限）／自分のAIで使う（任意）／有料（月300〜480円目安）＋ページ最下部に「PR」表記のアフィリエイト。AIの提案に広告を混ぜない
- 利用状況は回数と日付だけ記録し、中身は運営にも見せない。最初に同意を取る（未実装）
- 開発は5段階＋3回の判断。見合わなければ引く

## 今どこか

段階1（試験運用の準備）。レシピ帳にある機能：

- 人ごとのレシピ帳（`data/users/<id>/...`）、みんなのレシピ（`shared/<id>`）、公開・取り下げ・保存
- 提案（カテゴリ厳守、調理環境、買い足し予算、買う理由・買わない方法・保存方法と期間）
- AIに相談（記録、メモに追加、レシピに反映）、調理環境（折りたたみ）
- AIのモード（節約 quick／ふつう default／しっかり complex、既定は節約）
- 共有で閲覧のみになったときの案内表示

## ベータ（claude.ai の外）

- 方針：claude.ai 版は編集者招待しか使えず参加者が限られるため、試験運用は Puter.js のウェブアプリで行う。一般公開では運営の API ＋日本語の画面・支払いに切り替える想定（AIを呼ぶ部分は差し替えられる作り）
- 最小版：`beta/index.html`（詳細は `beta/README.md`）。節約モード固定、提案（1品／2つ以上選ぶと献立）・何人分（1〜6人、調理環境の「いつも作る人数」が初期値）・保存・手入力でのレシピ追加と編集・料理の写真・調理環境・使用量の記録
- 状態：仮の Puter で流れを確認済み。**本物の Puter ではまだ未確認**。置き場所（Netlify Drop など）を決めて公開し、ログイン画面の言語・提案・保存を確かめる
- 進み具合：Puter のアカウント作成と Netlify への公開は完了（2026-11-19）。Puter の無料枠は **月1,000クレジット**、保存容量 **200MB**（Puter の使用量画面で確認）
- 測定結果（2026-11-20、節約モード＝claude-haiku-5-5、9回）：1品 約6クレジット（10〜15秒）、献立2品 約17クレジット（25〜34秒）。消費の約96%はAIの出力トークン。kv はほぼゼロ。月1,000で1品なら約170回、献立なら約57回。献立を毎日2回使う人以外は無料枠に収まる見込み。「ふつう」（約20倍）は無料枠では現実的でない
- 未確認：写真の保存（Puter の Storage が 0 Bytes のまま）
- 以前の予定：節約モードで10〜20回使い、Puter の無料枠の減り方から「普通に使うと月どれくらいか」を見積もる
